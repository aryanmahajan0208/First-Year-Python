# First-Year-Python

A collection of lab exercises, assignments, and mini-projects completed during my 1st Year of CSE AI-DS at MIT-WPU.

---

## Languages and Tools:
- Programming in: Python 3.10+ (3.14.6)
- Environment: Windows 11 (25H2) / VS Code

## Unit-wise Breakdown:
* **Unit I: Python Fundamentals & Data Structures**
  * IDE, Python Language, and Syntax
  * Data Types and I/O
  * Basic Operators
  * Built-in Data Structures
    * List
    * Tuple
    * Dictionary

* **Unit II: Control Structures & Functions**
  * Control Structures
    * Conditional Statements
    * Loop Control
  * Functions
    * Definition and Calling
    * Parameters
    * Recursion

* **Unit III: Python for Data Analysis & Visualization**
  * Standard Modules & NumPy
    * Arrays and Array Processing
    * Slicing
  * Introduction to Pandas
  * Data Preprocessing
  * Data Visualization
    * Matplotlib
    * Seaborn

* **Unit IV: Pattern Matching with Regular Expressions**
  * Regex Basics and Wildcard Characters
  * Match Function
  * Search Function
  * Search and Replace
  * Extended Regex
